# Terminal de Agentes PUJ · Dunder Mifflin × Pied Piper

Oficina en pixel art de agentes de IA (Claude Code) dentro del aeropuerto de Punta Cana: cada tarea es un vuelo,
con pantalla de salidas, radio de torre, OTP A15 y cielo real de PUJ.

Esta versión pública corre una **jornada simulada en bucle**. La versión en vivo, conectada a los agentes reales,
corre en local.
